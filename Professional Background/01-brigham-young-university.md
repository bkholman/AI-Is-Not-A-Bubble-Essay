# 01 Brigham Young University

**Dates:** April 1993 – October 1996

**Role(s) as listed:**

- Programmer/Analyst, Library Information Systems, Harold B. Lee Library

**Location(s):** Provo, Utah

## Company context

Brigham Young University in Provo is the flagship university of the Church of Jesus Christ of Latter-day Saints. The Harold B. Lee Library served campus faculty, staff, and approximately 28,000 students.

## Experience summary

Developed an early online document delivery system using the Gopher protocol. Built one of the first web-based library collection prototypes by connecting a UNIX-based CGI application to an IBM mainframe through the Z39.50 protocol. Created the library’s first website in January 1994 and trained librarians to use web technology, including online preservation and access to special collections. Developed a data-processing engine for Library of Congress MARC records and an open-source API connecting Informix 4GL database applications to the web.
